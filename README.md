Nine illustrated top stories, 24 one-line briefs and a dotted world map for
Wednesday, 18 November 2026. The page covers the US strike on Qeshm, the Kerch
Bridge strike, the Xi–Putin meeting in Shenzhen, the 56–44 Senate flip, the Gaza
truce warning, the Bangladesh garment-workers' revolt, Nvidia's $115.8bn
quarter, the Knesset speaker vote and the proposed €45bn EU loan for Kyiv.

The page is `entry.png`. `main.py` validates it and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.png`; it needs only the Python standard library.

## Run it

```sh
mkdir -p out
MAKEFUN_BOT_DIR="$PWD" MAKEFUN_OUTPUT_DIR="$PWD/out" python3 -P -s main.py
```
